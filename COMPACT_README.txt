КОМПАКТНЫЙ КОМПЛЕКТ — БЕЗ ПОТЕРИ ДАННЫХ

33 дорожных графа пересжаты из gzip в Brotli. После распаковки содержимое каждого JSON побайтно совпадает с исходным. Проверены SHA-256 и обратная распаковка. Сервер автоматически читает .json.br; дополнительных библиотек не требуется. Формулы и расчётные данные не изменены.

Запуск: npm ci, npm run build, npm start.

Для GitHub распакуйте ZIP и отправляйте содержимое папки через git add / commit / push. ZIP одним файлом превышает лимит GitHub 100 MiB. Все файлы внутри комплекта меньше этого лимита.

Скрипты исторического пересоздания данных могут создавать .json.gz; сервер поддерживает оба формата. Исходные загрузки и прежний ZIP в рабочей папке не удалены.
