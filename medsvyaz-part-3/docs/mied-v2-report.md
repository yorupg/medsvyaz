## Источники и данные

- Населённые пункты и население: [Росстат / «Если быть точным», перепись 2021](https://tochno.st/datasets/allsettlements). Полные локальные CSV трёх пилотов и происхождение по ОКТМО — в `data/raw`; наблюдаемая выборка 16 других регионов — `data/processed/target-settlement-samples.json`.
- Дороги пилотов: [Geofabrik, Калининград](https://download.geofabrik.de/russia/kaliningrad.html), [OSM extract Ивановской области](https://download.openstreetmap.fr/extracts/russia/central_federal_district/ivanovo_oblast-latest.osm.pbf), [OSM extract Псковской области](https://download.openstreetmap.fr/extracts/russia/northwestern_federal_district/pskov_oblast-latest.osm.pbf). Использованы сохранённые снимки 08–09.11.2026, времена рассчитаны по [таблице скоростей OSRM v5.27.1](https://github.com/Project-OSRM/osrm-backend/blob/v5.27.1/profiles/car.lua).
- Больницы: [ТФОМС Калининградской области](https://tfoms39.ru/medicalfacilities/register-medical/), [ТФОМС Ивановской области, реестр 01.09.2026](https://tfoms37.ru/images/Doc/reestr/TR_MO_2026_01.09.2026.xlsx), [официальные документы Псковской областной клинической больницы](https://www.pskovokb.ru/home/official-documents.html) и локальные подтверждающие документы для выбранных площадок. Объекты с неподтверждённым типом не включены.
- Границы: исторический слой geoBoundaries 2017 из уже имеющихся файлов проекта; это не актуальная административная верификация.

## Проверка

Для трёх пилотов `python3 scripts/recalculate_v2.py` независимо повторил кратчайшие пути по направленному графу и сформировал контрольные JSON и CSV. Проверены диапазон 0–100, покрытие относительно всех строк исходных файлов, координаты, подтверждённый статус больниц, суммы вкладов пунктов, монотонность при τ = 30/45/60/90 и отсутствие строк с синтетическим происхождением в переписных выборках. Python синтаксис скриптов проверен.

Сборка TypeScript, тесты Vitest и проверка страниц в браузере не выполнены: Node.js отсутствует в среде; сетевой доступ для его получения не был разрешён. Это оставляет риск ошибки интеграции интерфейса и API.

## Ограничения и дальнейшие данные

- Для 17 регионов отсутствуют локальные проверенные реестры стационаров и автомобильные графы. Ни один индекс для них не подставлен.
- Для трёх пилотов медицинские площадки составляют выборку, а не полный реестр; больницы и дороги соседних регионов не включены.
- 3, 7 и 13 пунктов соответственно не имеют пути в локальном графе. Пока это непроверенный маршрут, а не доказанная автомобильная изоляция; эти пункты исключены из знаменателя.
- Скорости, геометрические подъезды к сети и периоды доступности являются модельными допущениями. Поворотные ограничения, пробки, переправы, фактический приём и наличие коек не подтверждены.
- Для полного расчёта каждого из 17 регионов нужны исходные строки всех населённых пунктов, подтверждённые больничные площадки, снимок автомобильных дорог с межрегиональными связями и проверка пропущенных маршрутов.
