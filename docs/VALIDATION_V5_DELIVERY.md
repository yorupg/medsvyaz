## Как проверить на локальном компьютере

```bash
npm ci
python3 scripts/verify_v5.py
npm test
npm run verify
npm run build
npm run dev
```

Открыть `/scenarios?region=pskov`, выбрать поселение в таблице или на карте, переключить `Исходная сеть` / `Сократить время участка`, выбрать `Маршрут выбранного поселения`, проверить кнопки **«Показать базовый маршрут»**, **«Показать улучшенный маршрут»**, **«Сравнить на карте»** и прирост индекса слева над картой. Затем выбрать **«Весь регион»** и убедиться, что выделенные дорожные объекты и числовые результаты изменились; маршруты для всей расчетной когорты должны быть пересчитаны, однако не обязаны измениться геометрически у каждого пункта. В разделе `/methodology` установить 8 и 0 минут: индекс учебной территории должен быть 100.

**Оговорка к методике:** основная версия v5 использует равные веса поселений по ранее принятой территориальной постановке; численность жителей сообщается отдельно. Не смешивать с историческим, взвешенным по населению индексом v3. При t≤15 минут доступность определяется как 100 — это выбранное командой исследовательское допущение, а не норматив Минздрава.
