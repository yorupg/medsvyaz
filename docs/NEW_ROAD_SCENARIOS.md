# МИЭД: новые дороги как проверяемые аналитические гипотезы

**Дата: 11.11.2026.** Это дополнение обновляет сведения о дорожных сценариях в ранее выпущенных PDF.

## Что изменилось

Автоматическая геодезическая прямая между далёкими населёнными пунктами заменена короткими **недостающими связями между существующими дорожными узлами** около населённых пунктов. Система предлагает варианты только при положительном фактическом модельном приросте индекса после запуска Дейкстры на изменённом графе. По результату можно выбрать затронутое поселение и сравнить исходный маршрут с маршрутом, использующим новый участок.

- Примерные ограничения генератора: длина 0,15–0,95 км, вблизи поселения (до 1 км от центра), существующие дорожные узлы в качестве концов, оценочная скорость 25 км/ч, без существующего ребра.
- Кандидаты берутся из `data/planning/algorithmic-road-candidates.json`, создаваемого `scripts/generate_road_candidates.py`; в таблице исходного списка отдельно сохранены модельные приросты и число изменённых маршрутов.
- Экран показывает **проектный эскиз** розовым пунктиром. Это не новая существующая дорога и не подтверждённый проект строительства.
- При одном проекте могут улучшиться только некоторые маршруты. Региональный режим автоматически выбирает затронутый пункт. При отсутствии подходящего варианта индекс не подгоняется и линия не рисуется.

## Безопасность и ограничения

Подбор автоматически исключает часть очевидных геометрически неподходящих кандидатов и названия военных объектов, но **не содержит полных официальных полигонов военных ограничений, охранных территорий и водных препятствий**. Поэтому НЕЛЬЗЯ утверждать, что кандидат безопасен или законен для строительства, включая Калининградскую область. Для принятия решения необходим официальный пространственный скрининг запретов, выездные обследования, геология, мостовые переходы, собственность и оценка экологии. Без этих процедур статус — «ПРЕДВАРИТЕЛЬНЫЙ ЭСКИЗ, ТРЕБУЕТ ПРОВЕРКИ».

Вопрос для жюри: **где целесообразно заказывать предпроектное обследование**, а не где завтра строить дорогу. Расчётный положительный индекс не означает экономической окупаемости. Сопоставляйте `ΔМИЭД`, число затронутых поселений, минутную экономию, CAPEX/OPEX и риск перед инвестиционным решением.

## Данные и воспроизведение

Репозиторий использует дорожные графы OSM и населённые пункты ВПН-2021; для пилотных больниц — данные ТФОМС, для части регионов — OSM hospital. Генератор использует SciPy Dijkstra для предварительной оценки; сайт независимо заново считает граф TypeScript. Это проверка **математической целесообразности**, не реальной безопасности трассы.

**Light:** маршрутизация и новые дорожные проекты на трёх пилотах; **Full:** дополнительные региональные графы (если для региона подготовлен подтверждённо результативный эскиз). При отсутствии проверяемого кандидата показано ограничение.

### Как найти поселение для проверки новой дороги

Откройте «Регионы», выберите регион и найдите блок «Где новая дорога сократит поездку?». Список отсортирован по экономии минут до больницы. Кнопка «Открыть предложение» выбирает поселение и его локальный сценарий на карте. Одна новая связь может улучшать поездки сразу из нескольких поселений.

При изменении порога доступности или скорости список пересчитывается. После обновления дорожных графов, списка кандидатов или методики пересоберите список для стандартных параметров командой `node --import tsx scripts/build-road-options.ts` из корня проекта.

### Калининградская область · проверка трассы и пользы

На странице региона откройте «Где новая дорога сократит поездку?». Изначально требуются экономия не менее 5 минут и сокращение не менее 10% времени от выбранного поселения до больницы. Пользователь может менять оба порога. В региональном режиме хотя бы один маршрут должен проходить оба условия. Список, карта и пересчёт используют одну геометрию трассы. Кнопка «Рассмотреть трассу и препятствия» показывает участок крупно вместе с фрагментом карты зданий и водных объектов. «Проверить улучшение существующей дороги» сравнивает сценарии при одинаковых параметрах сети и поездки.

Проверены шесть ранее отобранных пар дорожных узлов. Полный снимок Geofabrik от 8 ноября 2026 года совпадает со снимком пилотного графа. Контуры зданий, водные мультиполигоны и линии водотоков, а также отмеченные ограждения и железнодорожные пути обрабатываются в метрической проекции EPSG:32634. Для ширины будущей дороги приняты 8 м и дополнительный запас 2 м с каждой стороны. Если ширина водотока неизвестна, используется приближение по его типу. В районе без нанесённых контуров зданий расчёт не принимает эскиз. Отсутствие препятствия в OSM не удостоверяет, что его нет на местности.

Поиск A* использует шаг 10 м и область поиска до 180 м вокруг ограничивающего прямоугольника исходной линии. Полная полоса проверяется после упрощения ломаной. Водное препятствие допускает проезд только по геометрии существующего доступного двустороннего автомобильного моста, представленного в дорожном графе. Максимальная длина соединения — 1 км. Длина принятой ломаной определяет вес нового ребра при модельной скорости 25 км/ч. Геометрическая проверка нужна для сравнения гипотез. Для проектирования нужны полевые обследования, кадастровые и инженерные материалы.

**Воспроизведение из корня проекта**

```sh
python3 -m pip install -r requirements-data.txt
curl -fLO https://download.geofabrik.de/russia/kaliningrad-261108.osm.pbf
python3 scripts/screen_kaliningrad_roads.py kaliningrad-261108.osm.pbf
node --import tsx scripts/build-road-options.ts
```

Генератор проверяет SHA-256 исходного снимка. Готовая геометрия и статический слой препятствий уже входят в поставку. Штатный запуск сайта через Docker не требует Python или скачивания геоданных.
