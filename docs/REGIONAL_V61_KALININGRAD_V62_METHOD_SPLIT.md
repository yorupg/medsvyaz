# МедСвязь 24/7 — разделение методик по регионам (патч 13.11.2026)

## Что меняется

**Россия, кроме Калининградской области** — МИЭД v6.1 со старыми весами:

S_i = 0.85 A(T1_i) + 0.10 A(T2_i) + 0.05 A(R_i)

T1 и T2 — времена по графу до двух разных по дорожному узлу БЕСПЛАТНЫХ медучреждений: существующих больниц и (при наличии в региональном каталоге) взрослых/детских государственных поликлиник. Частные платные клиники не включаются. R — время в стресс-сценарии дорожной сети по прежней методике v6.1.

**Калининградская область** — отдельная экспериментальная методика v6.2:

S_i = 0.55 A(H_i) + 0.35 A(P_i) + 0.10 A(R_i)

H — ближайшая больница, P — ближайшая поликлиника, R — устойчивость больничного маршрута. Сохранены результаты и кнопки отдельных сценариев в Калининградской области.

**Общая часть для обеих методик**:

I = 100 × Σ_i (0.752/N + 0.248 p_i/P) S_i

Возрастные группы не входят в индекс. Два метода НЕ СЛЕДУЕТ сравнивать как одинаковые рейтинговые оценки.

## Источники и ограничения

При расчёте для регионов, кроме Калининграда, добавляются только записи государственных/муниципальных поликлиник из `public/data/medical-catalogs/<region>.json`, которые содержат действующий `roadNodeId` и не обозначены частными. Государственная организация с платными услугами остаётся государственной. Важное ограничение: отметка public в OSM не доказывает бесплатный приём по ОМС или нужный медицинский профиль; перед реальным планированием нужна проверка в официальном реестре.

Исходный перечень больничных площадок не подменяется новыми неподтверждёнными больницами OSM. Если у региона пока нет классифицированных поликлиник с привязкой к графу, v6.1 продолжает рассчитываться по имеющимся больницам, с предупреждением о неполноте списка.

## Установка

В корне `medsvyaz-main` (рядом с `package.json`) выполнить:

```bash
unzip -o ~/Downloads/MedSvyaz24_Methods_Split_Russia_Kaliningrad_PATCH.zip
docker compose up --build -d
```

Проверить версии:

```bash
curl -s http://localhost:5173/api/study/kaliningrad | python3 -c "import json,sys; print(json.load(sys.stdin)['medicalMethodologyVersion'])"
curl -s http://localhost:5173/api/study/ivanovo | python3 -c "import json,sys; print(json.load(sys.stdin)['medicalMethodologyVersion'])"
```

Ожидаемые значения: 6.2.0 для Калининграда и 6.1.0 для Ивановской области. Порт может отличаться в вашем Docker Compose.

Для проверки расчёта:

```bash
docker compose exec <имя_сервиса> npm test -- --run tests/medical-method-split.test.ts
```

Или на Mac при установленных Node-зависимостях:

```bash
npm run typecheck
npm test -- tests/medical-method-split.test.ts
```
