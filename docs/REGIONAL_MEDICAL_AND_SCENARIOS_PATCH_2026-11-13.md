# Региональные медицинские карты, индекс и предложения — обновление

## Что входит в обновление

- Кнопки «Предложить больницу с поликлиническим отделением», «Предложить новую дорогу», «Исходная сеть» доступны для других регионов, помимо Калининградской области, включая синтетические модели. Они запускают расчёт на уровне региона с текущими `τ` и масштабом времени, а не открывают неподключённую панель.
- На странице реального региона загружается его собственный `public/data/medical-catalogs/<region>.json`: больницы, взрослые/общие поликлиники, детские поликлиники и частные клиники обозначаются и фильтруются отдельно. Исходные расчётные больницы остаются видны.
- Синтетические каталоги (52) создаются воспроизводимо по населению и географии модельных поселений, без выдачи их за реальные учреждения.
- При наличии поликлинических точек с привязкой к дорожному графу сервер рассчитывает МИЭД v6.2 = 0,55 доступности больницы + 0,35 доступности поликлиники + 0,10 устойчивости больничного маршрута. Возрастные группы НЕ включены в общий индекс. Территориальный и демографический веса остаются 0,752 и 0,248.
- Без пригодных поликлинических данных остаётся исторический v6.1 и предупреждение об отсутствии данных, вместо искусственного приравнивания отсутствия сведений к отсутствию помощи. **Регионы v6.1 и v6.2 напрямую сравнивать как единый рейтинг нельзя**.
- Кнопки инфраструктурных сценариев используют модельный подбор одной площадки/дороги. Это гипотезы, а не проверенные проекты строительства и не подтверждение профиля медучреждения.
- При сравнении сценариев учитывается улучшение интегральной оценки поселения (в том числе амбулаторного компонента), даже если время до стационара не меняется.

## Обязательно выполнить после распаковки

При работающем интернете в корне проекта Mac, с активным Python-окружением, содержащим `brotli`, `numpy`, `scipy`:

```bash
python scripts/refresh_all_region_medical.py
```

Команда скачивает OSM-производные точки, отбирает по геометрии регионов, классифицирует по имеющимся признакам, удаляет близкие дубли, привязывает поликлиники к дорожному графу и обновляет 85 региональных JSON. Также пересчитывает сохранённые предложения Калининградской области. **Интернет требуется для новых географических точек**, которые не вошли в ZIP.

Если скачивание не удалось, можно повторить; уже загруженные тайлы кэшируются в `data/medical-osm-cache`. При полностью недоступном интернете используйте `--offline` только для повторной обработки ранее сохранённых тайлов — новые учреждения это не добавит.

Затем выполните:

```bash
docker compose up --build -d
```

Только после этого сервер увидит новые поликлиники и начнёт рассчитывать индексы v6.2 в соответствующих регионах.

## Как проверять результат

1. Выберите Ивановскую, Псковскую или другую реальную область; проверьте ненулевые значения «Поликлиники» в легенде карты. Если их нет, проверьте вывод импортёра: в некоторых регионах OSM может быть неполным.
2. В верхней карточке проверьте версию индекса. По версии 6.2 рядом со временем до больницы отдельно выводится P90 до поликлиники.
3. Нажмите «Предложить больницу...» либо «Предложить новую дорогу». В блоке сравнения должно появиться моделируемое изменение или сообщение, что среди проверенных кандидатов решения нет. Если проект найден — его эскиз отображается на карте.
4. Для синтетического региона все учреждения и связи должны сопровождаться указанием условного характера данных.

## Ограничения и источники

Источники: OpenStreetMap ODbL (https://www.openstreetmap.org/copyright), архив OSM-точек в открытом наборе https://github.com/01shane89-jpg/AXIOM-APSAP, исходные данные поселений ВПН-2021 из проекта. Отбор по `amenity=hospital/clinic`, русскому имени и оператору лишь предварительный; он не является проверкой действующей лицензии, круглосуточной госпитализации, категорий граждан, фактической платности или бесплатности услуг. Пробелы OSM особенно вероятны в сельских районах. Частные клиники не входят в основной расчёт бесплатной амбулаторной помощи.

Для всех 33 реальных регионов можно автоматически импортировать OSM-каталог; заявить, что **все** реальные больницы, поликлиники и частные медицинские центры найдены и официально подтверждены, на этих данных нельзя.

GitHub-репозиторий обновление не изменяет.
