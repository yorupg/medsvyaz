## Алгоритм выбора дорожных улучшений

1. Построить базовые кратчайшие маршруты для всех населённых пунктов к допустимым больницам (многоисточниковый Дейкстра на обратном направленном графе).
2. Сформировать кандидатов из OSM-way (для синтетики — из отдельных ребер), **лежащих на базовых путях**; модельные подъезды исключить. Для каждого кандидата вычислить прогнозный прирост `A(max(0,t−Δt))−A(t)`, где `Δt` — сумма времён ребер на этом OSM-way, умноженная на `(1−1/multiplier)`. Для регионального сценария суммировать этот прирост по поселениям с равными весами; для конкретного пункта учитывать только его путь.
3. Выбрать лучший кандидат для одного поселения или до **4 лидирующих OSM-way** для региона; детерминированно разрешать равенства по экономии времени и ID. Это эвристика по базовым путям, а **не доказательство глобально оптимального бюджета**.
4. Изменить времена выбранных участков сети, затем **заново пересчитать все пути и индекс**; сообщить фактическое изменение, а не прогнозную оценку этапа 2. Путь может остаться тем же при меньшем времени или смениться на другой.
5. Сохранить базовую когорту поселений. Не объявлять неизвестный маршрут недостижимым. Не выдавать выбранные дороги за предложенные к реальному строительству без инженерной и экономической проверки.

## Новая функция доступности

```
A(t) = 1                            , 0 ≤ t ≤ 15 мин
     = 2^(-(t − 15)/(τ − 15))        , t > 15 мин
I_R = 100 × sum(A(t_i)) / N_R
τ = 40 мин (по умолчанию), допустимая чувствительность 30, 40, 50, 60 мин
```

- `A(0)=A(8)=A(15)=1`; учебные времена 0 и 8 минут дают индекс 100.
- `A(40)=0.5`; `A(65)=0.25`; конечные поездки длиннее τ остаются различимыми.
- Формула v5 непрерывна, но имеет излом в точке 15 минут; это осознанное модельное допущение, **не клинический норматив**.
- Значения v2, v3 и v4 хранятся как исторические версии; не сравнивать их без указания методики.

## Как проверить после установки зависимостей

```bash
npm ci
python3 scripts/verify_v5.py
npm test
npm run verify
npm run build
npm run dev
```

Открыть `/scenarios?region=pskov`. Выбрать поселение на карте. Проверить обе кнопки и сравнение на карте; переключить масштаб улучшения на «Маршрут выбранного поселения», затем на «Весь регион», проверить выбранные дороги и Δ индекса. Проверить таблицу и JSON/CSV. В `/methodology` установить 0 и 8 минут — результат должен быть 100. При замене исходных графов заново выполнить `npm run calculate`.
