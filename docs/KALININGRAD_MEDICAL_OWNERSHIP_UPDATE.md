# Калининградская область: государственные учреждения и частные платные клиники

Патч для `yorupg/medsvyaz` (ветка `main` проверялась **только на чтение**; SHA при подготовке `d71669e645d9879bd19aa8f349b43d4d2f9d96fc`). Никаких операций записи в GitHub не выполнялось.

## Главное правило

**Форма собственности определяется независимо от наличия платных услуг.**

- `Государственные больницы (+)` — организации с подтверждающим признаком государственной/муниципальной формы собственности; наличие `fee=yes` не меняет категорию.
- `Государственные поликлиники (П)` — взрослые, а при отсутствии точного профиля возраст может быть не подтверждён.
- `Государственные детские поликлиники (Д)` — с явным детским профилем.
- `Государственные амбулатории и ФАП (А)`.
- `Прочие государственные медучреждения (Г)` — не смешиваются с амбулаториями/больницами.
- `Частные платные клиники (₽)` — требуется **два независимых признака**: частный оператор и платный приём (`fee=yes` либо ручная проверка с источником).
- `Требуют проверки (?)` — нет достоверного признака собственности, оплата не подтверждена для частной клиники либо данные противоречивы. По умолчанию скрыты на карте, включаются фильтром. Никогда не объявляются государственными или частными платными автоматически.

Например, если государственная поликлиника предоставляет платные услуги, она **всегда остаётся в государственном слое**. Участие частной клиники в ОМС не делает её государственной. Наличие `fee=yes` без сведений о собственнике не делает клинику частной.

## Что добавлено в базу данных

- `data/reference/kaliningrad-public-organizations-2026.json` — 31 наименование государственных медицинских организаций, собранное из опубликованного тарифного соглашения ОМС 2026 г. и дополнительного перечня подведомственных учреждений 2022 г. Это **не полный список медицинских точек/филиалов**.
- `data/reference/kaliningrad-public-organizations-2026.csv` — таблица этих же юридических организаций с явно пустыми координатами для дальнейшей привязки. Отсутствующие координаты не выдуманы.
- `public/data/kaliningrad-public-organizations-2026.json` — доступная сайту копия справочника имён.
- `scripts/build_kaliningrad_medical_catalog.py` — импортёр географических точек OSM для всей Калининградской области с новой классификацией собственности и оплаты. Создаёт JSON для карты и CSV для ручной проверки.
- `data/manual/kaliningrad-medical-review-TEMPLATE.csv` — отдельный шаблон ручных подтверждений, не перезаписывающий заполненный `data/manual/kaliningrad-medical-review.csv`.

**Важное ограничение:** интернет-доступа к Overpass API в среде подготовки не было, поэтому архив **не включает полный геокодированный каталог**. Без успешного импорта новые точки не появятся на карте. Распакованным ZIP нельзя подтвердить, что все больницы, поликлиники и частные клиники уже добавлены. Официальный реестр организаций не содержит в готовом виде всех координат филиалов и не заменяет ФРМО.

## Как применить ZIP поверх своего проекта

Из корня проекта (`package.json`, `src`, `server`):

```bash
unzip -o ~/Downloads/MedSvyaz24_Kaliningrad_Ownership_2026_PATCH.zip
```

Если у вас **уже был собран OSM-каталог прежним импортёром**, обновите его классификацию без сети:

```bash
python3 scripts/build_kaliningrad_medical_catalog.py --from-existing
```

Если каталога **ещё нет** или вы хотите актуализировать набор OSM-точек, используйте:

```bash
python3 scripts/build_kaliningrad_medical_catalog.py
```

Этот шаг должен выполняться на компьютере с доступом к Overpass. Программа не заменит существующий JSON неполной выборкой (<30 объектов), если не указан явный тестовый `--allow-small`. При ошибке сети сохранённая база остаётся прежней.

Результат:

- `public/data/kaliningrad-medical-facilities.json` — точки с координатами, классом, источником и статусом проверки;
- `data/derived/kaliningrad-medical-facilities.csv` — вся полученная выборка для аудита.

Допускается импорт собственного файла ответа Overpass:

```bash
python3 scripts/build_kaliningrad_medical_catalog.py --input /путь/к/overpass-response.json
```

Запуск сайта: `npm run dev` (при установленных зависимостях). После появления каталога на странице Калининградской области под картой доступны фильтры по всем видам учреждений. Объекты имеют отдельные значки, название в подсказке/попапе, адрес при наличии в OSM и первоисточник. Подписи показываются при масштабе 12 и выше.

**Не копируйте пустой шаблон поверх своего заполненного файла ручной проверки.** Чтобы начать работу с нуля: создайте `data/manual/kaliningrad-medical-review.csv` на основе файла `-TEMPLATE.csv`.

## Ручная проверка

Для спорных объектов используется `data/manual/kaliningrad-medical-review.csv`, где `id` — исходный ID OSM. Возможные значения:

| Колонка | Значения |
| --- | --- |
| `confirmedOwnership` | `public`, `private`, `unknown` |
| `confirmedFeeStatus` | `paid-confirmed`, `free-confirmed`, `unknown` |
| `confirmedMedicalType` | `hospital`, `adult_polyclinic`, `children_polyclinic`, `ambulatory`, `other_clinic` |
| `officialSourceUrl` | Ссылка на документ, доказывающий указанные сведения |
| `officiallyVerified` | `yes` только после сверки конкретного объекта и адреса |

Поправки о собственности и платном приёме не принимаются без HTTPS-ссылки на подтверждение. Приоритет публичной собственности сохраняется и после ручной проверки, независимо от `paid-confirmed`.
