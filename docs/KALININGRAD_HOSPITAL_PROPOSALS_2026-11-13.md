# Калининградская область — исправленный портфель медицинских учреждений (13.11.2026)

## Результат и способ применения

В блоке «Поселения, больницы и маршруты» нажмите **«Предложить решение для Калининградской области · 3 учреждения»**. Переключатель устанавливает **исходный граф, τ = 40 минут и множитель ×1**. Все три проекта активируются **одновременно**. Выбор карточки справа только приближает проект на карте; он не включает / отключает проект. Кнопка «Скрыть предложения и сравнение» возвращает исходное отображение. Для изменения сценария используйте стандартный селектор.

Три площадки на текущем этапе:

| № | Населённый пункт | Категория | Предполагаемая услуга | Вклад в региональный МИЭД |
|---|---|---|---|---:|
| 1 | Домново | Государственная больница | Госпитализация и круглосуточный стационар (сценарное допущение) | +2,79 |
| 2 | Советск | Государственная взрослая поликлиника | Амбулаторный дневной приём | +0,00 |
| 3 | Мамоново | Государственная взрослая поликлиника | Амбулаторный дневной приём | +0,00 |

Модельный МИЭД v6.1 для исходной сети **73,96**, после всего портфеля **76,75**, суммарный прирост **+2,79** балла. Поликлиники **не подменяют стационар**, поэтому по действующей формуле стационарной транспортной доступности напрямую не изменяют МИЭД. Для них показан **отдельный модельный возрастно-взвешенный амбулаторный охват**. Эти величины не следует складывать как баллы одного индекса.

## Алгоритм

- Дорожный граф и время — исходные OSM рёбра, вес в минутах, алгоритм Дейкстры; дубли параллельных рёбер при построении графа агрегируются по **минимальному**, а не суммарному весу.
- Из 964 поселений 959 имеют вычислимую оценку МИЭД v6.1; 5 сохраняют **неопределённый статус**, а не искусственные нули. Файл `public/data/kaliningrad-hospital-proposals.json` содержит 964 индивидуальные записи `portfolio.pointResults` (базовое / новое время, базовая / новая оценка, больница назначения, резервный маршрут, стресс-тест).
- По исходной методике МИЭД v6.1 индивидуальная доступность включает ближайший стационар (85%), резервный (10%), стресс-сценарий перекрытия (5%). Региональная оценка объединяет 75,2% поселений и 24,8% населения. Формулу при введении возрастов **не изменяли**.
- Для отбора проектов учитываются **возрастные веса 1,4 (0–17 лет), 1,0 (18–54), 1,6 (55+)**; это **авторские коэффициенты социального приоритета**, а не медицинские нормативы. Возрастные доли городских и сельских жителей области — из Росстата 2021, применены к численности каждого поселения ВПН-2021. Возраст **по каждому конкретному поселению не измерен**.
- Рассматриваются государственные бесплатные больницы, взрослые и детские поликлиники как разные типы проектов. Условие первого этапа портфеля — хотя бы один круглосуточный стационар с положительным приростом МИЭД. В местах, где модельное время до стационара >= 35 минут, амбулаторная поликлиника не рассматривается как его замена. Далее тип определяется по доступности больниц и нанесённых поликлиник, охвату соответствующей возрастной группы и близости к существующему дорожному узлу.
- Для поликлиник используем **возможную амбулаторную доступность** в маршрутах к OSM-точкам. Источник не полон: результаты — гипотезы для первичной проверки, **не доказательство отсутствия поликлиники в Советске или Мамоново**.
- Все три объекта размещаются на существующих дорожных узлах возле населённых пунктов. **Участки земли не проверены**. Нужны данные о лицензиях, мощностях коечного фонда, доступности услуги, транспортных ограничениях и стоимости.

## Как исправлен интерфейс

1. **Десять исходных больничных площадок** в `data/processed/kaliningrad-pilot.json.br` имеют профиль стационара: их прежние белые значки заменены красными `+`, как в категории государственных больниц.
2. Группа **«Вид учреждения не определён»** и отдельная опция **«Подписи начиная с масштаба 12»** по умолчанию выключены.
3. Три звезды на карте и три карточки справа соответствуют разным типам проектных учреждений. Карточка приближает нужную звезду.
4. При активном портфеле карта перекрашивает **каждое поселение по результату после совместного сценария**, таблица «Расчёт по каждому пункту» использует такие же индивидуальные оценки и времена, а верхний МИЭД и «Сравнение вариантов» показывают **73,96 → 76,75**. Для всех значений МИЭД применяется точность до двух десятичных знаков.
5. В сравнении вместо нуля затронутых жителей показывается **население затронутых поселений**; отдельно — число жителей поселений с улучшенной поездкой к стационару. Это не оценка числа реальных пациентов.
6. На карте базовая трассировка остаётся **исходным маршрутом**. Новые времена/баллы рассчитаны по графу, но маршруты ко всем новым площадкам графически не прорисованы. Это ограничение указано в блоке деталей — линия не выдаётся за новый путь.

## Источники и воспроизведение

- Росстат (официальный бюллетень): https://rosstat.gov.ru/storage/mediabank/Bul_chislen_nasel-pv_01-01-2021.pdf
- ВПН-2021 по поселениям: https://tochno.st/datasets/allsettlements
- OpenStreetMap: https://www.openstreetmap.org/copyright
- ТФОМС области (организации ОМС): https://tfoms39.ru/medicalfacilities/register-medical/

Пересчитать локально (зависимости Python: numpy, scipy, brotli):

```bash
python3 scripts/build_kaliningrad_facility_proposals.py
python3 -m unittest discover -s tests -p 'test_kaliningrad_*.py'
```

На сайте достаточно распаковать ZIP-патч поверх корня проекта, где находится `package.json`; готовые JSON уже включены. `main` на GitHub не изменялась. Для полной проверки фронтенда отдельно запустите `npm ci && npm run build && npm test` — установка npm зависимостей в данной рабочей среде недоступна.
