# Поселения с неожиданно низкой доступностью

Откройте «Регионы» → «Калининградская область» и оставьте исходную сеть, τ = 40 мин и масштаб времени 1. В блоке «Где доступность ниже ожидаемой?» выберите пункт и нажмите «Показать маршрут на карте».

## Расчёт

Единица анализа — населённый пункт. Источник координат, больниц и длин дорожных рёбер — региональный пилот полного релиза v5.1. Дневной базовый расчёт МИЭД v5 использует 10 выбранных больничных площадок. В выборку вошли 959 из 964 пунктов. Пять пунктов без привязки к узлу исключены. Целевой показатель — дорожный балл поселения от 0 до 100. Вес каждого пункта одинаковый.

Признаки описывают расположение: расстояния по большой окружности до первой и второй ближайших площадок и число площадок в пределах 15 и 30 км. Дорожные времена, дорожный балл и длина рассчитанного маршрута не входят в признаки. Для каждого из 22 муниципалитетов стандартизация признаков и обучение выполняются на остальных муниципалитетах. Регрессия k ближайших соседей даёт средний балл 20 аналогов по евклидову расстоянию в стандартизированных признаках. Разрыв равен ожидаемому баллу минус дорожный. Первая десятка положительных разрывов показана на сайте.

## Проверка и интерпретация

Средняя абсолютная ошибка прогнозов по исключённым муниципалитетам — 8,32 балла. Для прогноза по медиане остальных муниципалитетов — 19,60. Эта проверка оценивает переносимость между муниципалитетами одной области. Результаты относятся к модельным поездкам и зависят от состава больниц.

Для сравнения рассчитан коэффициент объезда: длина самого быстрого маршрута, включая подъездные связи, делится на расстояние по прямой до той же площадки. Минимальное расстояние для этого сравнения — 1 км, выборка — 952 пункта. Совпадение первых десяток составляет 6 из 10. Совпадение описывает различие двух способов отбора. Доказательство причины плохой связи требует разбора маршрута и проверки на местности.

Для Вороново (Гурьевский муниципальный округ) дорожный балл составляет 58,48 при ожидаемых 92,31. Его коэффициент объезда равен 1,30 и даёт 467-е место из 952. Здесь полезно сравнить две площадки: ближайшую по прямой и выбранную по времени через дорожную сеть. Обе указаны в карточке, если различаются.

## Воспроизведение

Готовые оценки загружаются из public/downloads/kaliningrad-peers.json. Полный список с исходным и ожидаемым баллами лежит рядом в kaliningrad-peers.csv. Для обычного запуска сайта достаточно стандартной инструкции проекта.

Для повторного обучения из корня проекта установите зависимости Node и Python в отдельном окружении (проверено с NumPy 2.3.5 и scikit-learn 1.8.0):

    npm ci
    python -m pip install numpy==2.3.5 scikit-learn==1.8.0
    python scripts/train_kaliningrad_peers.py

Скрипт сам запускает расчёт на графе через Node и перезаписывает JSON и CSV. Чтобы обновить уже собранный клиент, повторите npm run build или docker compose up --build.
