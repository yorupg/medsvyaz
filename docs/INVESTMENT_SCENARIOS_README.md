# Сценарии v5 · новая дорога и новая медплощадка

## Как пользоваться

1. Откройте `/scenarios?region=pskov` в Docker.
2. В поле **«Сценарий»** выберите «Предложить новую дорогу · проект» или «Добавить медплощадку в модель · гипотеза».
3. Масштаб «Весь регион» автоматически подбирает один кандидат: для дороги он соединяет два реально существующих узла сети условной прямой; для медицинской площадки выбирает существующий населённый пункт. В «Маршрут выбранного поселения» оптимизируется доступность выбранного пункта. Если подходящий вариант не найден, программа честно показывает нулевой эффект, а не искусственный маршрут.
4. Нажмите **«Показать пункт с изменённым маршрутом»**, чтобы выбрать пример. На карте используйте «Базовый маршрут», «Улучшенный маршрут» и «Сравнить на карте».
5. Маркер **?** обозначает гипотетическую медицинскую площадку, **розовый пунктир** — гипотезу нового дорожного коридора. Существующие больницы помечены знаком +.
6. Сравните значения МИЭД, изменение времени, число поселений и жителей. Стоимость и окупаемость обосновываются в `docs/ECONOMIC_JUSTIFICATION_A2_2026-11-11.md`.

## Как выбрать решение научно корректно

- Существующий скоростной сценарий *может не изменить геометрию* маршрута. Это нормально: сокращается время по прежней дороге.
- Новый проектный коридор не должен восприниматься как реально пригодное место для дороги. Алгоритм ограничивает расстояние 1–28 км, проверяет экономию ≥6 минут для кандидата и затем **полностью пересчитывает граф**. Геометрия — лишь прямая между узлами, не учитывающая инженерные ограничения.
- Проектная медплощадка добавляется в перечень допустимых точек назначения для исследования. Необходима верификация: в выбранном городе может уже существовать профильная больница, пропущенная исходным набором.
- Нельзя ранжировать реконструкцию дороги и строительство больницы по ΔМИЭД без CAPEX, OPEX и проверенных ограничений. Сначала провести аудит медучреждений, затем отдельный финансово-экономический анализ.
- МИЭД v5 использует равные веса поселений; население и количество затронутых жителей показываются дополнительно.
