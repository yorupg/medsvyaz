## Быстрая ручная проверка в Docker
1. `docker compose -p medsvyaz24-v5 up -d --build` из папки проекта; порт по умолчанию `5180`, для параллельного запуска со старой версией в PowerShell сначала установить `$env:MEDSVYAZ_PORT='5181'`.
2. Открыть `http://localhost:5181/scenarios?region=pskov`.
3. Сценарий `Предложить новую дорогу` + `Весь регион`, нажать `Показать пункт с изменённым маршрутом`, нажать `Сравнить на карте`; убедиться в появлении розового проектного коридора, нового сегмента маршрута и ненулевого Δ индекса.
4. Сценарий `Добавить медплощадку в модель`, увидеть проектный маркер `?`, изменения назначения и Δ индекса; обратить внимание на предупреждение о непроверенном медицинском профиле.
5. Сценарий `Ускорить существующую дорогу` может иметь одинаковую геометрию базового/улучшенного маршрутов — так и должно быть, если меняется лишь время на тех же дорогах.
6. Сравнить значения API `/api/study/pskov/compare?scenario=new_road&scope=region` и `/api/study/pskov/compare?scenario=new_facility&scope=region`.
