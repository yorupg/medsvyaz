# Исследовательский ML-модуль: необычно сложные поездки

## Что решает

МИЭД v5 оценивает поездку к выбранным медицинским площадкам по **дорожному графу**. Новая ML-модель отвечает на другой вопрос: где итоговая оценка заметно хуже, чем у **географически похожих** поселений? Она не участвует в формуле индекса и не корректирует результаты маршрутизации.

## Данные и признаки

Для доступного полного реального набора берутся только поселения с валидными координатами и **рассчитанным достижимым** маршрутом, с одинаковыми профилем медицинской помощи, периодом и τ. Наблюдаемая цель `yᵢ = 100 × A(tᵢ; τ)` — балл по направленному дорожному графу. Модель не обучается на этом же балле как входном признаке.

Признаки:
1. `dᵢ` — расстояние по сфере (haversine) от поселения до ближайшей допустимой медплощадки (км), без учёта дорог;
2. `nᵢ(50)` — число допустимых медплощадок в радиусе 50 км по прямой.

Для устойчивости используются `log(1+dᵢ)` и `log(1+nᵢ(50))`, нормализованные по распределению обучающей выборки. Данные о медицинских площадках имеют те же ограничения подтверждения, что и основной МИЭД.

## Алгоритм

`k`-ближайших соседей (kNN-регрессия), `k = clamp(floor(sqrt(N_train)), 8, 20)`. Предсказание — взвешенное по `1/(0.15 + расстояние в пространстве признаков)` среднее целевых баллов соседей. Своё значение `yᵢ` **всегда исключается** из прогноза поселения `i`. При наличии больше 1600 поселений тренировочный набор ограничен 1600 детерминированно по хешу ID (для контроля времени выполнения). Минимум — 30 пригодных пунктов.

`gapᵢ = ŷᵢ − yᵢ`. В списке отображается до 8 пунктов с наибольшим положительным разрывом, если `gapᵢ ≥ max(15, 1.5 × MAE_LOO)`. `MAE_LOO` — средняя ошибка при предсказании каждого обучающего пункта без использования его собственной оценки. Это внутренняя, **не независимая** и не пространственно разнесённая проверка, не гарантия обобщающей способности модели.

На сайте показаны ожидаемый/фактический баллы, разрыв, геодезическое расстояние до ближайшей больницы, её название, количество больниц в радиусе, время дорожного маршрута и назначенная алгоритмом больница. Выбор поселения раскрывает **фактическую геометрию рассчитанного дорожного пути** на региональной карте (если полный граф включён).

## Важные ограничения

- Большой разрыв нельзя автоматически интерпретировать как отсутствующую дорогу или показание к строительству.
- Причиной могут быть река и мост, разрешённые направления, въезд в учреждение, неполный медицинский перечень, ошибки геокодирования, привязки или дорожной модели.
- Ближайшее по прямой учреждение может отличаться от дорожного назначения.
- Для регионов без доступного полного графа ML не показывается как рассчитанная оценка, а выводится сообщение о недоступности.
- Значения сценариев `до / после` по-прежнему рассчитываются отдельно алгоритмом Дейкстры. ML обучается на **исходной сети** при выбранных τ и множителе времени; сценарии не смешиваются с обучением.

## Проверка

`npm test` — unit-тесты включают отчётность об аномалии, пропусках и минимальной выборке. Для защиты желательно дополнительно вручную открыть 3–5 найденных пунктов, сверить линию маршрута и данные OSM/реестра больниц; без такой проверки находки нельзя трактовать как подтверждённые проблемы инфраструктуры.
