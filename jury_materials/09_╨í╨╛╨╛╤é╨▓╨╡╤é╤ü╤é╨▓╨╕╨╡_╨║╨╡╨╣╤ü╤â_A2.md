# Проверка соответствия требованиям кейса A2

Основание: файл организаторов `2 кейс.pdf`, презентация `5_Кейс_чемпионат`, материалы команды. Экономическая окупаемость **не названа в брифе обязательной**, но усиливает практическую ценность инструмента.

| Требование A2 | Реализация / подтверждение | Ограничение |
|---|---|---|
| Выбрать цель индекса | Доступность выбранных медплощадок на автомобиле | Не скорая помощь и не качество лечения |
| Обосновать территории | 33 региональные модели из реальных исходных данных, 52 отдельные учебные модели | Не национальное измерение, неоднородность профиля |
| Определить «хорошую связность» | Время маршрута и A(t); контрольные точки τ | τ и комфорт 15 минут — авторское допущение |
| Единое правило сравнения | МИЭД v5, фиксированные версия, τ, профиль | Не объединять официально подтверждённые/неподтверждённые площадки |
| Понятный инструмент | Карты, графы, перерасчёт, CSV/JSON, раздел «Методика» | Карта может требовать интернет для OSM тайлов |
| Несколько сценариев | Модернизация действующей дороги, медплощадка, проверенный новый коридор, перекрытие | Новая дорога в реальном регионе не допускается без внешней предпроверки |
| Сравнение до / после | Изменение индекса и времени, маршруты, социальный охват | Путь может не поменяться визуально при улучшении скорости |
| Практическое решение | Приоритет аудита больниц, затем вариантов с обоснованной стоимостью | Нужны смета и ограничения для инвестрешения |
| Воспроизводимость | Исходные файлы, методика, скрипты, независимая проверка | Реальные времена и медпрофили не везде верифицированы |
| ИИ и проверка | Отдельная ведомость ИИ, тесты и независимые источники | Команде подтвердить фактически использованные инструменты |
| Финальная дорожная карта | Источники → проверка медицинских данных → сценарии → сметы → пилот | Требуются внешние согласования |

**Материалы для жюри:** презентация интерфейса, паспорт, научная методика, реестр данных, зарубежные аналоги, экономики, решения, риски, тесты, роль ИИ. Все перечисленные материалы лежат в `jury_materials/` и/или по ссылке Google Drive из README.

## Рекомендованный выступающий тезис

«Мы создали авторский индекс транспортной доступности выбранных медицинских площадок для оценки типичного поселения. Система помогает обнаружить неудобные транспортные связи и честно сравнивать гипотезы инфраструктурных улучшений. Алгоритм не проектирует дороги через запретные зоны: новые строительные коридоры принимаются только после документированной проверки. Финансовую окупаемость не выдаём без смет и денежных потоков».


> **Дополнение от 11.11.2026:** сценарий коротких новых дорожных связок снова доступен как **модельный эскиз**, но ни одна трасса не признана безопасной для строительства. Подробности в `docs/NEW_ROAD_SCENARIOS.md`; этот текст уточняет прежнюю формулировку о полном отключении новых дорог.
