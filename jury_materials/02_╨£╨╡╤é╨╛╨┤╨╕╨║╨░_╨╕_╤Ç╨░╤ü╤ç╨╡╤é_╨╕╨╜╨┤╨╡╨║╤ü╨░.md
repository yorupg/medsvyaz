# Методика МИЭД v5.0: определения, расчёты и проверки

## Что измеряет индекс

Потенциальную **автомобильную транспортную доступность выбранного множества медицинских площадок** для поселений в рамках определённого дорожного графа. Это индекс территориальной равномерности: каждое *включённое* поселение имеет равный вес. Результат не является медицинским нормативом и не измеряет фактическое время до начала лечения.

## Исходные данные и модель

- Узлы/дуги `G=(V,E)` с идентификаторами OSM, направленностью, разрешённостью и модельным временем; `t_e=length_e/speed_e * 60` минут.
- Поселение `i`, связанное со своим узлом `v_i`; проверенные в рамках выбранного профиля площадки `H`.
- Время `t_i=min_{h in H} shortest_time_G(v_i,h)`, вычисляется многоисточниковым алгоритмом Дейкстры на обратном направленном графе.
- Для пересмотра сети создаётся *копия* графа с допустимым изменением, затем рассчитываются **все маршруты заново**. Действующая сеть остаётся неизменной.

## Функция доступности

```
A(t; τ) = 1                              при 0 <= t <= 15 мин
        = 2^(-(t - 15)/(τ - 15))         при t > 15 мин, τ > 15
I_R = 100 * [Σ_{i included} A(t_i; τ)] / N_included
τ = 40 минут по умолчанию
```

**Контрольные точки:** `A(0)=A(8)=A(15)=1`; `A(40)=0,5`; `A(65)=0,25`; `A(90)≈0,125`. При изменении `τ` нельзя напрямую пересчитывать только итоговый индекс — требуется пересчитать вклады всех поселений. Параметры 15 и 40 требуют обоснования и проверки чувствительности (`τ=30/40/50/60`), не представляют юридический норматив.

## Почему не веса жителей

В основной версии показатель отвечает на вопрос «как обеспечен типичный населённый пункт?». Он не означает «как обеспечен типичный житель?». Чтобы не скрывать социальный масштаб, отдельно показываются численность затронутых жителей и охват по временным порогам. Использование одинаковых весов нельзя подменять утверждением, будто все люди получили одинаковый вес.

## Обработка отсутствующих данных

Подтверждённо недостижимый путь в рассматриваемом сценарии может получать нулевую доступность. **Отсутствующий из-за неполных дорожных/медицинских исходников путь не является доказанной изоляцией**: он помечается как неизвестный и исключается из сравнимой оценки с отдельным показателем покрытия. Для сравнения «до/после» нужен одинаковый набор учитываемых поселений.

## Отбор и оценка сценариев

1. Зафиксировать профиль, дату входных данных, географию, `τ` и допущения.
2. Для реконструкции дороги выбрать допустимые существующие OSM-way на исходных кратчайших путях по прогнозному приросту доступности, затем пересчитать все пути фактически.
3. Для дополнительной медплощадки проверить несколько населённых пунктов-кандидатов, пересчитать маршруты с добавленной точкой; **реестровая проверка перед рекомендацией обязательна**.
4. Для *новой дороги на реальной территории* не строить линию «по воздуху». Принимать только заранее проверенную планировочную полилинию из `data/planning/approved-road-corridors.json`, содержащую документальные подтверждения проверки ограничений. Сейчас реестр пуст: это осознанное ограничение.
5. Рассчитывать `ΔI=I_after-I_before`, выигрыш времени, число поселений с изменениями и их справочную численность населения; отдельно проверять `CAPEX/OPEX` и экономический эффект.

## Наглядный пример и ограничения

**Псковская область, прежний учебный сценарий:** базовый индекс в версии v5 был около `37,05`; добавление условной площадки в Опочке увеличивало показатель примерно на `7,40` балла. **Это прежде всего проверка полноты исходного перечня медицинских площадок:** в Опочке есть официально известное медицинское учреждение; до полной сверки ФРМО нельзя заявлять потребность в новом строительстве. Прежний автоматический дорожный коридор исключён из инвестиционных предложений как недостаточно безопасный.

Алгоритмическая валидация маршрутов (независимые реализации) доказывает **согласованность вычислений**, но не достоверность скоростей, законность строительства, достаточность больниц, реальную нагрузку на них и не заменяет мультимодальный расчёт с расписаниями.
