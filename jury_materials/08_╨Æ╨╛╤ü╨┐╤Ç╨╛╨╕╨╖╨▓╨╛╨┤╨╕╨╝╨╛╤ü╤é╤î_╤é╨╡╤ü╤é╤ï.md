# Воспроизводимость, проверки и ограничения

## Архитектура

Frontend: React + TypeScript + Vite + Leaflet. API: Node.js + Hono. Дорожная модель: `shared/engine.ts`, схемы данных: `shared/schema.ts`, сервер исследования: `server/study.ts`, карта: `src/components/StudyMap.tsx`, сценарии: `src/components/StudyWorkspace.tsx`. Данные включены в локальный проект; есть gzip/br дорожные графы, выгрузки CSV/JSON и журналы происхождения.

## Повторить установку

```powershell
cd "C:\путь\к\medsvyaz24"
$env:MEDSVYAZ_PORT="5181"
docker compose -p medsvyaz24-final up --build -d
```

Открыть: `http://localhost:5181/scenarios?region=pskov` или главную. Для Node 22.13+: `npm ci`, `npm run build`, `npm start`. Примечание: в каталоге проекта должен существовать `data/processed` и `data/derived`; облегчённый пакет GitHub без данных требует сначала восстановить их из Google Drive.

## Регрессионные тесты

- `tests/engine.test.ts`: классические вычисления на тестовом графе.
- `tests/methodology-v5.test.ts`: комфортная зона 0–15, τ и веса поселений.
- `tests/investment-proposals.test.ts`: реальные новые связи не допускаются без подтверждений; синтетические примеры помечаются учебными; дополнительная медплощадка меняет назначение только при фактическом эффекте.
- `scripts/verify_v5.py`: независимый пересчёт в другой реализации на основании исходных времён.
- `npm run calculate:final`, `npm run verify`, `npm run build`: пересчёт, аудит и сборка.

## Что означает успешная проверка

Совпадение TypeScript и Python доказывает **правильность реализации заданной модели**, а не истинность скоростей OSM, актуальность больниц, проходимость дороги в снег или безопасность нового строительства.

## Дефект известных экономических данных

Невозможно получить реальную окупаемость только из географических координат, МИЭД и численности жителей: нужны годовые поездки и денежные потоки. Отсутствие этих входов явно отражено в документации.

## Состояние проверки поставки

В среде подготовки **не удалось выполнить полную `npm ci`/`npm run build` из-за неполных npm-зависимостей**; поэтому заключение о полностью протестированной браузерной версии не даётся. В пакете сохранены исходники, тесты, инструкции и контроль исходной структуры. Перед защитой команда должна выполнить сборку на локальном компьютере/Docker и открыть все ключевые страницы.
