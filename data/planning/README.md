# Новые дороги: два разных уровня проверки

## 1. Автоматические короткие эскизы (новый режим)

Список `algorithmic-road-candidates.json` содержит **аналитические варианты**, а не юридически или инженерно разрешённые дороги. Генератор `scripts/generate_road_candidates.py`:

1. Работает с реальным направленным графом дорог OSM и маршрутами к выбранным медицинским площадкам.
2. Ищет короткие новые связи примерно 150–950 м между различными существующими дорожными узлами в пределах 1 км от населённого пункта с численностью от 200 человек.
3. Не берёт уже существующее ребро, длинную прямую через регион или узлы с подозрительными дорожными/топонимическими названиями (военный, гарнизон, полигон, лагерь и др.). Дополнительно выбирает кандидатов, близких к другим существующим дорогам.
4. Для каждого кандидата **заново считает кратчайшие маршруты и индекс**. Только при положительном результате кандидат попадает в реестр.
5. После нажатия на сайте результат ещё раз проверяется расчётным движком. Прокладывается отдельная проектная связь; нулевой эффект не называется улучшением.

**ВНИМАНИЕ: этот фильтр НЕ подтверждает безопасность.** Данные в проекте не содержат исчерпывающих границ военных объектов, ООПТ, водных и земельных ограничений. Проектный пунктир — только *эскиз для дальнейшего анализа*. Никакое отсутствие тега `landuse=military` в исходном графе нельзя использовать как доказательство отсутствия военной территории. **Нельзя утверждать, что предложенный коридор проверенно безопасен или строить дорогу по этим координатам.**

Для проверки нужен отдельный этап наложения официальных геоданных: военные/запретные зоны, кадастр, ООПТ, водные переходы, рельеф и существующие коммуникации; затем экспертная трассировка, стоимость и экологическая оценка. Если это не подтверждено — статус «НЕ УТВЕРЖДЕНО, ТРЕБУЕТ ПРОВЕРКИ».

Генерация (для включённых в проект графов):

```bash
python scripts/generate_road_candidates.py --regions kaliningrad ivanovo pskov
```

Требуются `numpy`, `scipy`, `brotli`. Результат пишется в `data/planning/algorithmic-road-candidates.json`.

## 2. Документированные коридоры (отдельный уровень)

В `approved-road-corridors.json` хранится **отдельный список** новых дорог, по которым выполнена предварительная проверка и приложены документы. Этот список сейчас пуст, и никакие автоматические эскизы не подменяют его. Чтобы добавить коридор, требуется:

- подтверждённая полилиния, узлы дороги и сведения о необходимости нового участка;
- официальная проверка военных ограничений, ООПТ, водных объектов и переправ;
- проверка права на землю, рельефа, дорожной безопасности и документов планирования;
- ссылки на документы/дату и ответственную организацию;
- обоснованная скорость, длина и анализ затрат;
- тест маршрутов и обязательное независимое подтверждение результатов.

Весь расчёт остаётся анализом гипотез, а не строительной документацией.
