# Допуск новых дорожных связей к моделированию

**По умолчанию список `approved-road-corridors.json` пуст.** Это намеренное правило безопасности, а не ошибка сайта. На реальных данных автоматические прямые дороги отключены: OSM-дорожный граф, время поездки и фотографии карты **не** подтверждают разрешимость строительства. В частности, нельзя считать отсутствие `landuse=military` доказательством отсутствия военной территории.

Для добавления конкретного кандидата эксперт по территориальному планированию должен:

1. Установить ID исходного дорожного набора `datasetId`, два допустимых `fromNodeId`, `toNodeId` и точную полилинию `geometry` в формате `[[longitude,latitude], ...]`, минимум три точки, которая действительно представляет возможный коридор, а не геодезическую прямую.
2. Проверить действующие военные ограничения и запретные территории **по официальным данным**; самостоятельно нанесённые объекты OSM не достаточны.
3. Проверить ООПТ и другие природоохранные ограничения, реки/переправы, права на землю, инженерно-геологические и дорожные требования, документы территориального планирования.
4. Задокументировать источники, даты проверки, орган, проводивший экспертизу; приложить ≥2 URL источников и выставить соответствующие `evidence` флаги `true` **только после подтверждения**.
5. Указать обоснованную среднюю проектную скорость `maxSpeedKmh` от 10 до 90 км/ч и отдельно оценить длину, CAPEX, OPEX, безопасность, экологию, риски.
6. Прогнать тесты `npm test`, `npm run build` и проверить геометрию на карте. Даже успешные тесты **не заменяют** согласований, кадастровой проверки или проекта дороги.

Пример структуры **без реальных координат**:

```json
{
  "version": 1,
  "corridors": [
    {
      "id": "документированный-идентификатор",
      "datasetId": "ID-набора",
      "title": "название обследованного коридора",
      "fromNodeId": "ID-узла-начала",
      "toNodeId": "ID-узла-конца",
      "geometry": [[0, 0], [0, 0], [0, 0]],
      "maxSpeedKmh": 40,
      "evidence": {
        "militaryRestrictions": false,
        "protectedAreas": false,
        "waterAndBridges": false,
        "landRights": false,
        "terrainAndSafety": false,
        "municipalPlan": false,
        "sourceUrls": []
      }
    }
  ]
}
```

Этот пример заведомо **не пройдёт валидацию** и не предназначен для копирования в действующий реестр. Для Калининградской области, пока отсутствует обоснованный и проверенный коридор, сайт возвращает «Новая дорога не предлагается автоматически» и **не рисует линейный проект через военный полигон**.

Для синтетических учебных графов по-прежнему допускается гипотетическое прямое ребро, но оно подписано как демонстрация, не строительная рекомендация.
