# Что изменено в проекте (09.11.2026)

## Уже было в ZIP (не переписывалось с нуля)

React/Vite-интерфейс, каталог 89 записей, API Hono, индекс из времён поездки и весов населения, выбор подходящих учреждений, сценарии закрытия и улучшения связи, существующие Vitest-тесты и единая страница учебного графа.

## Новые данные

- `data/processed/geometries.json`: ранее пустой файл заменён на 83 исторические геометрии для интерактивной карты (справа — данные geoBoundaries ADM1 2017, ODbL). `data/regions.json`: `isoCode` заполнен источниковым `shapeISO` только для 83 сопоставленных объектов; официальные коды всё ещё не утверждаются.
- `data/derived/representative-points.csv` и `representative-points.json`: опорные точки внутри исторических полигонов; не координаты городов и больниц.
- `data/derived/geodata-manifest.json`: условия использования, время источника, степень упрощения, шесть отсутствующих геометрий.
- `data/examples/{kaliningrad,ivanovo,tyumen}.json`: три **синтетических** примера; имена регионов лишь подписи географических контекстов. `data/examples/manifest.json`: перечень и ограничения.
- `data/derived/example-*.csv`, `scenario-summary.csv/json`: воспроизводимые входы и результаты алгоритма для модели и сценариев.

## Интерфейс и API

- `/materials` — новая страница: карта, проверка примеров, переключатели сценариев и порогов, подробная таблица пунктов, выгрузка GeoJSON/CSV/JSON.
- `/api/geo-summary`, `/api/examples`, `/api/examples/:regionId/dataset`, `/api/examples/:regionId/compare` — новые маршруты.
- Ссылки на страницу материалов добавлены в навигацию, главную страницу, сведения о проекте и футер.
- `data/team.json`: указаны имена **Соловьева Полина, Сурайкина Алена, Матренина Милана, Грезина Анна, Толокова Юлия**. Прежние направления работы обозначены как предварительные, потому что персональные обязанности не были указаны.

## Запуск и проверка

- Добавлены `Dockerfile`, `docker-compose.yml`, `.dockerignore`; локальный Node.js Windows не требуется.
- В `package.json` исправлен `build`: удалён вызов отсутствовавшего `scripts/build-worker.mjs`. Команды, ссылавшиеся на отсутствующие скрипты, заменены действующими.
- `scripts/build_geodata.py` — повторная генерация карты из исходного GeoJSON (требует `shapely` только при регенерации);
- `scripts/build_examples.py` — повторная генерация синтетических наборов и CSV;
- `scripts/calculate.ts` — пересчёт учебных таблиц «до/после»;
- `scripts/verify.ts` — автономная проверка набора геоданных, API и сценариев;
- `docs/calculation-materials.md`, `docs/passport-A2.md` и `README.md` — исходные данные, гипотеза, формула, контроль корректности, роль ИИ, ограничения.

**Проверено:** `tsc --noEmit` без ошибок, `scripts/verify.ts` успешно прошёл, `scripts/calculate.ts` получил таблицу результатов, базовые файлы и compose YAML проверены. **Не удалось проверить в данной среде:** полноценную сборку Vite и визуальное отображение через браузер — в распакованных зависимостях отсутствует нативный бинарник Rollup для Linux glibc; Dockerfile устанавливает правильные зависимости внутри Alpine. После запуска у пользователя стоит выполнить `docker compose exec web npm test` и проверить страницу в браузере.

**Не выполнено:** импорт настоящего дорожного графа, медицинских учреждений и населения трёх регионов. Реальные индексы остаются неопределёнными. Текст Google Docs также не был доступен полностью и потому не проверен на дословное соответствие.
