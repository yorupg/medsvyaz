# МедСвязь 24/7 · команда HTTPS · кейс А2

Версия **0.3.0**. Три пилота на реальных исходниках, 86 моделей с синтетической сетью, понятный разбор поездки и 89 исторических контуров на карте. Аватарки команды сохранены.

## Запуск

Распакуйте архив, откройте папку `medsvyaz24_v030` в терминале при работающем Docker Desktop:

```bash
docker compose up --build
```

Откройте **http://localhost:5180**. Версия внизу страницы — **0.3.0**. Старые копии на 5173/5174 могут продолжать работать; проверяйте адрес. Остановка этой копии: `Ctrl+C`, затем `docker compose down`. Если 5180 тоже занят:

```bash
MEDSVYAZ_PORT=5181 docker compose up --build
```

Откройте тогда http://localhost:5181. Без Docker, с Node.js 22.13+:

```bash
npm ci
npm run dev
```

Производственный запуск: `npm run build`, затем `npm start`. Python для запуска сайта не нужен. Дорожные графы уже подготовлены и входят в архив.

## Реальные пилоты

Профиль: автомобильная поездка к ближайшей из **выбранных государственных стационарных площадок**. Перепись — 2021, дороги OSM — 08–09.11.2026. Время рассчитывается моделью, не измеряется.

| Область | Поселений в источнике | Площадок | Индекс, T=60 | Покрытие населения источника |
|---|---:|---:|---:|---:|
| Калининградская | 1 098 | 10 | 78,904333 | 99,9722% |
| Ивановская | 3 049 | 5 | 59,307895 | 99,9746% |
| Псковская | 8 383 | 6 | 58,998030 | 99,9020% |

Индексы относятся к выборке больниц, **не образуют рейтинг медицинской помощи**. В Псковской области шесть площадок включают филиалы; это не шесть независимых организаций. Даты обновления официальных HTML неизвестны, дата скачивания не переименована в дату актуальности.

Поселения дальше 500 м от допустимой дороги не включены, покрытие показано. Включённые недостижимые пункты остаются в знаменателе с нулевой оценкой. Независимый SciPy Dijkstra совпадает с TypeScript с погрешностью менее 1e-9 балла для каждого пилота.

Формула: `I = 100 × Σ[p × max(0, 1 − t/T)] / Σp`.

## Синтетические модели

В 81 модели используются реальные координаты и переписное население выбранных поселений (до 60 точек: 12 крупнейших и пространственно разнесённые малые). В пяти моделях без достаточного набора точек — по 48 условных поселений в историческом контуре и веса из распределения Калининградского пилота. Это **не** сведения о местной демографии.

Дороги и центры условные. Минимальное дерево и два ближайших соседа дают локальную сеть с альтернативами, а не звезду. До четырёх условных центров расположены у крупных точек; городской подъезд добавлен отдельно, поэтому население города не получает нулевую поездку. Длины и скорости откалиброваны по маршрутам трёх реальных пилотов. Seed фиксирован SHA-256.

Калибровка делает допущения объяснимыми, но не доказывает точность для других регионов. Моря, горные перевалы, переправы и сезонные разрывы в условной сети не восстановлены. Значения относятся только к выборке и не являются региональным рейтингом. Реальные и синтетические результаты не объединяются в индекс России.

## Проверка и пересборка

```bash
npm test
npm run verify
npm run build
```

Повторный расчёт сценариев и чувствительности по трём реальным пилотам занимает несколько минут:

```bash
npm run calculate
```

Полная пересборка графов использует включённые исходные PBF, CSV и адресные выборки:

```bash
python3 -m pip install -r requirements-data.txt
python3 scripts/build_pilot.py --region kaliningrad
python3 scripts/build_pilot.py --region ivanovo
python3 scripts/build_pilot.py --region pskov
npm run synthetic:build
npm run calculate
```

Пересоздание выборок синтетических моделей из полного национального CSV не нужно для запуска. Опционально загрузите архив из https://tochno.st/datasets/allsettlements и передайте его в `python3 scripts/prepare_synthetic_samples.py /path/to/settlements_data.zip`; затем повторите генератор. Отобранные исходные строки уже сохранены в `data/raw/synthetic-samples.json`.

Детали исследования: `docs/RESEARCH.md`. Источники и лицензии: `data/sources.json`. Контрольные суммы: манифесты в `data/raw` и метаданные готовых графов.

## Ограничения и лицензии

Упрощённый профиль скоростей OSRM v5.27.1 ограничен maxspeed и некоторыми покрытиями. Направления и явные запреты доступа учитываются; повороты, трафик, ожидание, вместимость больниц и медицинские направления — нет. Паромы и выезд за регион исключены. Привязка до 500 м при 5 км/ч — геометрическое допущение, не проверенный въезд. Одна точка представляет всё поселение. «24/7» — название проекта, не подтверждённый режим больниц.
