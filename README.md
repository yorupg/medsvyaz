## О проекте

**МедСвязь 24/7** помогает сравнивать потенциальную транспортную доступность выбранных медицинских учреждений в российских регионах и оценивать результат возможных изменений транспортной сети.

Система позволяет:

- 🗺️ рассматривать региональные индексы и карту населённых пунктов;
- 🏥 изучать расположение выбранных медицинских площадок и модельные автомобильные маршруты;
- 🔀 сравнивать исходную сеть со сценариями «до / после», в том числе изменения времени и индекса;
- 📍 находить проблемные населённые пункты и оценивать масштаб затронутого населения;
- 📊 анализировать варианты улучшений и их ограничения;
- 💰 рассматривать сценарную экономическую эффективность — **без выдуманной финансовой окупаемости**.

**Что показывает индекс:** потенциальную доступность выбранных медицинских площадок *по модельному автомобильному времени*. Он **не** измеряет фактическое время скорой помощи, качество лечения, загруженность больниц или наличие автомобиля у каждой семьи.

### Методика МИЭД v5.0

Для времени поездки `t` и параметра `τ > 15` минут:

```text
A(t) = 1,                           если 0 ≤ t ≤ 15 минут
A(t) = 2^(-(t - 15)/(τ - 15)),       если t > 15 минут

МИЭД = 100 × среднее A(t) по поселениям с рассчитанными маршрутами
```

По умолчанию `τ = 40 минут`. Поездки до 15 минут образуют условную «комфортную зону»; при 40 минутах доступность равна 50 баллам. В основной версии методики **поселения имеют одинаковый вес**, а численность населения учитывается в дополнительных социальных показателях. Это **авторские исследовательские настройки**, не официальные нормативы медицинской помощи. Пропуски и неполнота покрытых маршрутов показываются отдельно.

**Данные:** 33 региональных набора на реальных исходных геоданных, а также отдельные синтетические учебные модели. Наличие объекта на карте OSM само по себе не подтверждает его медицинский профиль или режим работы. Детали — в [методике](jury_materials/02_Методика_и_расчет_индекса.pdf) и [источниках](jury_materials/03_Датасеты_и_источники.pdf).

### Безопасность предлагаемых улучшений

В реальных регионах система **не должна рекомендовать строительство новой дороги по автоматически проведённой прямой**: такие линии могут пересекать военные, природоохранные и иные ограниченные территории. Новый коридор допустим к модельной оценке только после документированной проверки ограничений и инженерной осуществимости. Сценарий новой медицинской площадки — гипотеза, требующая проверки существующих учреждений и их специализации. См. [матрицу рисков](jury_materials/07_Риски_и_безопасность.pdf).

## 🚀 Запуск через Docker

Понадобится **Docker Desktop**. Скачайте архив, распакуйте его и откройте PowerShell **в папке с файлом `docker-compose.yml`**.

### Lite (из GitHub)

```powershell
docker compose -p medsvyaz24-lite up --build -d
```

Откройте **http://localhost:5182**. Пример сценариев: **http://localhost:5182/scenarios?region=pskov**.

### Full (из полного ZIP)

```powershell
$env:MEDSVYAZ_PORT="5183"
docker compose -p medsvyaz24-final up --build -d
```

Откройте **http://localhost:5183**. Порт `5183` выбран, чтобы не конфликтовать с ранее запущенными версиями на `5180`–`5182`.

Если сайт не открылся, проверьте состояние и логи, подставив используемое имя проекта:

```powershell
docker compose -p medsvyaz24-lite ps -a
docker compose -p medsvyaz24-lite logs --tail=100 web
```

Для локальной проверки исходников доступны `npm test` и `npm run build` после `npm ci`. Полноценный запуск требует Docker/Node.js и наличия региональных данных, соответствующих выбранной версии.
