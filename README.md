## Кратко о проекте

**Проблема.** Формальное наличие дорожной сети и медицинских учреждений не гарантирует, что жители разных населённых пунктов могут добраться до подходящей медицинской помощи за сопоставимое время. Средние региональные показатели могут скрывать труднодоступные поселения.

**Наш подход.** «МедСвязь 24/7» строит маршруты по дорожному графу, рассчитывает авторский **МИЭД — индекс транспортной доступности медицинской помощи**, сравнивает регионы и моделирует, как изменится доступность после транспортного вмешательства.

**Практическая задача:** помочь выявить проблемные территории и предварительно сравнить варианты улучшений **до принятия инвестиционного решения**. Система не заменяет медицинское, градостроительное или инженерное обследование.

### Что означает «предложить новую дорогу»

Алгоритм ищет **не существующую в расчётном графе короткую связь** между дорожными узлами вблизи населённых пунктов. Кандидат рассматривается только при положительном изменении результатов после пересчёта маршрутов. На карте он показывается как **предварительный проектный эскиз**.

> ⚠️ **Это не утверждённая и не подтверждённо безопасная трасса.** Автоматический расчёт **не располагает полным набором официальных данных** о военных зонах, землепользовании, охраняемых территориях, водных объектах, геологии и инженерных ограничениях. Перед любой рекомендацией о строительстве необходимы независимые проверки и предпроектные изыскания. Подробнее: [как предлагаются новые дороги](docs/NEW_ROAD_SCENARIOS.md) и [риски и безопасность](jury_materials/07_Риски_и_безопасность.pdf).

## Как считается МИЭД

В текущей методике v5.0 комфортная зона поездки составляет **до 15 минут**. Для времени \(t\) доступность задаётся функцией:

$$
A(t)=\begin{cases}
1,&0\le t\le15,\\[3pt]
2^{-\frac{t-15}{\tau-15}},&t>15,
\end{cases}\qquad \tau=40\ \text{мин по умолчанию}.
$$

Для региона индекс усредняет доступность **по включённым в расчёт населённым пунктам**, с одинаковым весом для каждого пункта:

$$
\mathrm{МИЭД}_R=100\cdot\frac{1}{N_R}\sum_{i=1}^{N_R}A(t_i).
$$

Здесь \(t_i\) — **модельное** время автомобильной поездки до выбранной доступной медицинской площадки. Численность населения анализируется **отдельно** и используется для оценки масштаба затронутых жителей; её не следует путать с весами основного индекса.

| Время в пути | Доступность при \(\tau=40\) |
| ---: | ---: |
| 0–15 минут | 100 баллов |
| 40 минут | 50 баллов |
| 65 минут | 25 баллов |

> Значение \(\tau\) и 15-минутная комфортная зона — **параметры авторской исследовательской модели, а не обязательный медицинский норматив**. МИЭД измеряет потенциальную автомобильную доступность выбранных площадок, **не качество лечения, не наличие свободных врачей и не время прибытия скорой помощи**.

Полная методика: **[PDF «Расчёт индекса»](jury_materials/02_Методика_и_расчет_индекса.pdf)** · [техническое описание](docs/NEW_ROAD_SCENARIOS.md).

## Данные и границы применимости

В проекте различаются данные и модели с разным статусом — **они не выдаются за одинаково надёжные измерения**:

| Группа | Что есть в проекте | Особенности |
| :--- | :--- | :--- |
| **3 исходных пилота** | Калининградская, Ивановская, Псковская области | Реальные дорожные графы и отобранные медицинские площадки; подробные сценарии доступны в Light и Full. |
| **30 дополнительных регионов** | Региональные данные, предварительно рассчитанные показатели | В Full — дополнительные дорожные графы; в Light — преимущественно готовые сводки без возможности пересчёта всех маршрутов. |
| **Синтетические модели** | 52 явно обозначенные учебные модели | Только моделирование; нельзя представлять как измеренную транспортную доступность региона. |
| **Без расчётных данных** | Отдельно обозначенные территории | Отсутствие оценки не следует заменять нулевым или вымышленным индексом. |

Основные источники: [OSM / Geofabrik](https://download.geofabrik.de/russia.html), [«Если быть точным» — населённые пункты](https://tochno.st/datasets/allsettlements), региональные сведения о медицинских учреждениях и исходные документы, перечисленные в [реестре датасетов и источников](jury_materials/03_Датасеты_и_источники.pdf).

**Ограничения:** дорожные времена модельные, часть учреждений получена из картографических источников без полной проверки медицинского профиля, расписания общественного транспорта и текущие пробки в базовый индекс не включены.

## 🚀 Запуск сайта на Windows через Docker

### Вариант A — FULL: рекомендован для полной демонстрации

1. **[Скачайте Full ZIP](https://github.com/yorupg/medsvyaz/releases/download/v5.1/MedSvyaz24_FULL_v5_1.zip)** и распакуйте архив.
2. Убедитесь, что [Docker Desktop](https://www.docker.com/products/docker-desktop/) запущен.
3. Откройте **PowerShell в папке проекта с `docker-compose.yml`**.
4. Выполните команды:

```powershell
$env:MEDSVYAZ_PORT="5185"
docker compose -p medsvyaz24-full up --build -d
```

5. Откройте **http://localhost:5185**. Для примера сценариев: **http://localhost:5185/scenarios?region=kaliningrad**.

### Вариант B — LIGHT: скачать код прямо из GitHub

Нажмите **Code → Download ZIP** в этом репозитории, распакуйте папку и выполните в ней:

```powershell
docker compose -p medsvyaz24-lite up --build -d
```

По умолчанию Light использует порт **5182**: http://localhost:5182.

**Light содержит детальные графы трёх исходных пилотов и региональные сводки, но не все графы Full.** Для расчёта маршрутов на остальных регионах скачайте Full.

Если сайт не открылся, проверьте:

```powershell
docker compose -p medsvyaz24-full ps
docker compose -p medsvyaz24-full logs --tail=100 web
```

Если порт занят, задайте другой `MEDSVYAZ_PORT` и повторите `docker compose up -d`. Для Light в диагностических командах используйте имя проекта `medsvyaz24-lite`.

## Научная и практическая корректность

- Положительное изменение индекса показывает **модельный эффект**, но само по себе не доказывает техническую осуществимость, безопасность строительства или окупаемость.
- Сценарий новой медплощадки сначала требует проверки полноты реестра уже существующих медицинских учреждений.
- Денежная окупаемость рассчитывается **только при заданных и обоснованных денежных потоках**; социальную пользу нельзя автоматически приравнивать к финансовой прибыли.
- Для корректного сравнения территорий необходимы сопоставимые медицинские профили, параметры формулы, версии данных и покрытие расчётов.
