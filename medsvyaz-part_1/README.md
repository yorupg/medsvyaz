# МедСвязь 24/7 · команда HTTPS · МАИ · кейс A2

Финальный проект: **МИЭД v4.0, τ=30, вес каждого поселения равен единице**. Население не входит в индекс. Сайт оценивает связанность поселений с выбранными больницами через дорожное время и помогает сравнивать транспортные улучшения.

```text
A(t) = 2^(−t/30)
I = 100 × Σ A(tᵢ) / N
```

33 реальных набора содержат 43 002 поселения и 946 выбранных больничных площадок. Ещё 52 региона представлены явно обозначенными синтетическими сетями; четыре территории имеют статус «Нет данных». Разные профили площадок и реальные/синтетические наборы не смешиваются в одном агрегате.

## Запуск

Нужен Node.js **22.13 или новее**:

```bash
npm ci
npm run build
npm start
```

Открыть **http://localhost:5180**. Если порт занят: `npm start -- --port 5181`. Разработка: `npm run dev`.

Или с Docker Desktop:

```bash
docker compose up --build
```

Другой порт: `MEDSVYAZ_PORT=5181 docker compose up --build`.

Python для обычного запуска не нужен. Все подготовленные графы включены; три исходных пилота также доступны в gzip без потерь, сервер читает их автоматически. Внешняя подложка OSM требует сети; контуры, точки, графы и расчёты доступны локально. GitHub Pages не запускает Node API; для размещения работающего сайта нужен Node/Docker-хостинг.

## Что умеет сайт

- Карта регионов с индексной заливкой, толстой границей реальных наборов и подсказкой «Реальные данные»; синтетические модели подписаны отдельно.
- Региональные карты с одинаковыми размерами точек по умолчанию, реальными координатами, больницами, выбранным маршрутом и таблицей вкладов поселений.
- Пересчёт кратчайших путей по направленному графу при улучшении или закрытии OSM-way; сохранение базового состава поселений при утрате маршрута.
- Медиана, P90, доли времени и полнота по поселениям; население показывается справочно и отдельно для социального охвата.
- Сценарная чувствительность при τ=20/30/45/60 и множителях времени.
- Бюджетное сравнение до пяти альтернатив: прирост нового индекса, время, новый охват, руб./балл, руб./новое поселение и справочно руб./нового жителя.
- Калькулятор NPV, ROI, простой и дисконтированной окупаемости. Прямые денежные потоки отделены от общественной оценки сэкономленного времени.
- CSV/JSON с исходными параметрами, источниками, формулами и результатами; PDF-паспорт.

Стоимость, инвестиции, годовые поездки и денежная оценка времени изначально неизвестны. Пользователь вводит их как сценарные допущения. Исторические бюджетные ориентиры Минтранса не подставляются в цену выбранных OSM-участков. При транспортном ущербе общественный NPV не выдаётся без модели его денежной оценки.

## Данные и ограничения

Поселения и население: ВПН-2021 / Росстат, публикация «Если быть точным». Дорожные графы и больничные объекты: OSM France. У трёх пилотов выбранные площадки сопоставлены с официальными источниками, у 30 наборов клинический профиль OSM официально не подтверждён. Контуры: geoBoundaries 2017, уточнение координат: OSM / GeoNames. Полный реестр: `data/sources.json`; происхождение объектов записано в наборах.

Методика v4 характеризует типичное поселение, а не типичного жителя. Нулевое или неизвестное население не исключает пункт из расчёта фиксированного набора. Подготовленные реальные перечни исторически ограничены пунктами с населением от 10 человек; это ограничение исходной выборки. Подтверждённая недостижимость даёт 0; непроверенный маршрут остаётся пропуском. Индекс не измеряет качество лечения, вместимость больниц, время ожидания и пробки. Одна координата города не описывает поездку от каждого дома. Синтетические дорожные времена и центры — фиксированные предположения модели, не реальные региональные оценки.

Архивы прежних методик: `public/downloads/archive/mied-v3-population` и `mied-v2-tau60`, с SHA-256. API позволяет воспроизвести прежние веса через `methodologyVersion=3.0.0` и старое τ через `methodologyVersion=2.0.0`.

## Проверка и пересчёт

```bash
npm run calculate:final
npm test
npm run verify
npm run build
node --import tsx scripts/audit-map-consistency.ts
```

`calculate:final` заново рассчитывает все 85 графов, проверяет независимые маршрутные времена, выполняет проверку Python и обновляет текущие таблицы. Старые сохранённые индексы не преобразуются в новые. `scripts/verify_v4.py` использует независимые `math.fsum`/`exp2`, единичные квантили и контрольные суммы снимков.

Браузерные проверки при запущенном сайте:

```bash
BASE_URL=http://localhost:5180 node scripts/browser-check.mjs
BASE_URL=http://localhost:5180 node scripts/economics-browser-check.mjs
```

Для них нужен Chrome или Chromium из Playwright. На другой ОС можно установить Chromium (`npx playwright install chromium`) и задать `CHROME_PATH`.

Паспорт пересоздаётся командой `npm run passport`. В комплекте уже есть готовый PDF. Для старых исследовательских скриптов, ожидающих несжатые пилоты: `python3 scripts/unpack_pilots.py`. Полный повтор сбора первичных PBF требует сети и Python-зависимостей из `requirements-data.txt`; источники, URL и контрольные суммы сохранены. Исторические отчёты v2/v3 не описывают текущие индексы.
