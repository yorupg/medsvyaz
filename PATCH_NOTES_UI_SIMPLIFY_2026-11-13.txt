Калининград — упрощение интерфейса и методологии

Что изменено:
1. Неопределённые медучреждения больше не выводятся на карту и не показываются в фильтрах.
2. Верхний блок «Главный результат» теперь показывает «Медучреждения на карте» вместо «Больничные площадки».
3. Упрощён блок параметров: оставлены только τ и чувствительность времён.
4. Убраны визуальные блоки:
   - сценарии дорожных улучшений в верхней панели,
   - «Где новая дорога сократит поездку?»
   - «Достоверность медицинских данных»
   - «Влияние отбора больничных площадок»
5. Добавлен новый текст методологии о выборе лучших решений для новых медучреждений.
6. На карте убраны кнопки быстрого запуска дорожных/медицинских сценариев для выбранного поселения; акцент оставлен на кнопках предложений над картой.

Затронутые файлы:
- src/components/StudyWorkspace.tsx
- src/components/StudyMap.tsx
- src/components/KaliningradMedicalOverlay.tsx

Примечание:
В контейнере не удалось прогнать финальный TypeScript build, потому что dev-зависимости для typecheck (typescript/vite type packages) в этом окружении неполные. Локально после распаковки патча рекомендуется выполнить обычный docker compose up --build или npm install && npm run build.
